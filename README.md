## The line

> My smart fridge locks me out after midnight like the cheese inside is in witness protection.

One line, 92 characters. The roast targets the smart fridge's own petty rule — it locks its owner out after midnight — and lands with a single surprising turn: the cheese isn't being kept fresh, it's in witness protection, hidden from the person who bought it. No second joke crowding it, and it reads like something you'd actually say standing at the fridge door.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, 1–200 characters). Python 3 standard library only, no network.
